## Codebase Patterns
- RepoRef now uses `repo_id` (field) instead of `repo_id()` (method)
- RepoRef now uses `clone_url()` method or `git_url` field instead of `git_url()` method
- Use `paths::repo_cache_path(&repo_ref)` to get full cache path for a repository
- For conflict checking with remote repos, extract base repo ID with `repo_id.split('/').take(3).collect::<Vec<_>>().join("/")`
- Local paths use `local:` prefix in repo_id, remote use `host/path` format
- Unit tests must use placeholder data: testowner, testteam, testrepo, test-skills, example.com, etc. (no real usernames)
- Git module: error messages must include repository path/URL and git's stderr (NFR-002)
- Agent struct mirrors Skill struct: same fields (repository, *_path, enabled, enabled_at, disabled_at) and helper methods
- Integration struct has skills_dir and agents_dir as Option<String>; use `if let Some(ref dir) = integration.skills_dir` pattern
- Use `paths::get_builtin_agents_dir(name)` for agent directories (returns None for codex)
- BuiltinIntegration struct in paths.rs has name, skills_dir (Option), agents_dir (Option)
- Use `scan_for_agents()` alongside `scan_for_skills()` to discover both types during repo add/upgrade
- When reconciling agents in upgrade, use `reconcile_agents()` parallel to `reconcile_skills()`
- Integration tests go in lib.rs when testing interactions between multiple modules (git, paths, commands)
- create_skill_symlink() is public for testing; uses unix_fs::symlink for directory symlinks
- Agent symlinks: FILE symlinks with .md extension pointing to AGENT.md
- Skill symlinks: directory symlinks pointing to skill folder (no .md extension)
- CLI subcommand groups follow pattern: SubagentAction enum mirrors SkillAction, handlers go in commands/subagent.rs
- Agent symlinks are FILE symlinks: `{agents_dir}/{name}.md` -> `cached/path/AGENT.md` (unlike skills which are directory symlinks)
- Use `paths::expand_tilde()` when working with user-provided directory paths (like agents_dir from config)
- Repository struct uses `url` and `path` fields (not `git_url` and `base_path`)
- Interactive mode (manage()) uses subagent::enable_with_lock() and subagent::disable_with_lock() for agent operations
